# Артикидс

Flutter-приложение для артикуляционных занятий. Врач назначает упражнение, ребёнок выполняет его перед фронтальной камерой, а кот повторяет движения рта. Результаты и рыбки сохраняются локально.

## Запуск веб-версии

Из корня проекта запустите HTTP-сервер для собранной папки `build/web`.

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory build/web
```

Откройте [http://localhost:8080](http://localhost:8080/) в Chrome или Edge. Для занятия разрешите браузеру доступ к камере и, если упражнение со звуком, к микрофону. Профиль и прогресс хранятся в IndexedDB этого браузера для указанного адреса. Для доступа к камере при размещении на сервере используйте HTTPS. [Доступ к камере и микрофону](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

Для пересборки на Windows из корня проекта выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tool\prepare_web.ps1
flutter build web --release --no-web-resources-cdn --pwa-strategy=none --no-wasm-dry-run
```

Скрипт подготовки создаёт локальные файлы SQLite и MediaPipe и копирует модель лица и эталон «а» из Android-ресурсов. Опубликуйте всю папку `build/web`, чтобы браузеру были доступны эти файлы. Камера и микрофон обрабатываются в браузере. Целевой звук во время занятия подтверждает врач. [Сборка Flutter Web](https://docs.flutter.dev/deployment/web) · [MediaPipe Face Landmarker для веба](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker?tab=Web)

## Запуск Android MVP

Требуются Flutter с Dart 3.11.4 или новее в ветке Dart 3.x и Android-устройство ARM64 с API 24+ и фронтальной камерой. Для упражнения со звуком нужен микрофон.

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
```

APK находится в `build/app/outputs/flutter-apk/app-release.apk`. В репозитории для демонстрационной сборки используется стандартный debug-ключ. Для проверки переноса данных устанавливайте обновление с тем же ключом поверх исходной версии.

### Открыть готовую сборку на Android-эмуляторе

Для камеры используется ARM64-библиотека MediaPipe. На Windows эмулятор Pixel_6 может запускать её через трансляцию ARM64. Проверьте, что среди ABI есть `arm64-v8a`, и установите APK поверх установленной версии.

```powershell
$adb = "$env:LOCALAPPDATA\Android\sdk\platform-tools\adb.exe"
& $adb devices
& $adb -s emulator-5554 shell getprop ro.product.cpu.abilist
& $adb -s emulator-5554 install -r --abi arm64-v8a .\build\app\outputs\flutter-apk\app-release.apk
& $adb -s emulator-5554 shell am start -n com.example.arti_kids/.MainActivity
```

Если `adb devices` показывает другой ID эмулятора, подставьте его вместо `emulator-5554`. Сборка версии 4 открывает главный экран с разделами «Уход», «Игры» и «Гардероб».

### Подключить Flutter-отладчик на Pixel_6

Для отладки на эмуляторе с основной архитектурой x86_64 передайте Flutter готовый **ARM64 debug APK**. Flutter установит его и подключится к процессу приложения.

```powershell
flutter run -d emulator-5554 --debug --no-pub --use-application-binary=build/app/outputs/flutter-apk/app-debug.apk
```

После изменения нативного кода или зависимостей пересоберите APK командой `flutter build apk --debug --target-platform android-arm64`.

## Сценарий для показа

На главном экране откройте «Магазин». Котик доступен сразу, а лисёнка, зайчонка и панду можно купить за заработанные рыбки. Покупка сразу выбирает персонажа. Между купленными персонажами можно переключаться бесплатно. После сохранения результата выбранный персонаж радуется и исполняет один из трёх случайных танцев. При включённом системном ограничении анимации остаётся радостная поза.

Детские разделы открываются с главного экрана.

- **Уход** показывает сытость, чистоту и настроение. Яблоко стоит 5 рыбок, печенье — 9. Купание и объятия бесплатны. После ухода показатели постепенно возвращаются к минимальному значению со временем.
- **Игры** открывают раунд «Поймай звёздочки». Пять пойманных звёзд дают 12 опыта. Раунд можно пройти в своём темпе.
- **Гардероб** предлагает скины «Пчёлка», «Садовник» и «Космонавт» для любого персонажа. Купленный скин можно надевать снова бесплатно. Он виден дома и во время упражнения.

У питомца общий прогресс при смене персонажа. Каждые 50 опыта повышают уровень. Подтверждённое занятие даёт 20 опыта, завершённая игра или уход также пополняют шкалу. Уровни пока отображают прогресс. Баланс, покупки, состояние питомца и опыт сохраняются в SQLite.

1. Откройте кабинет врача через кнопку в верхней части экрана и задайте локальный код взрослого. Нажмите «Назначить упражнение», выберите «Открой рот и скажи “а”», один повтор и награду в 10 рыбок.
2. Вернитесь на детский экран и начните назначение. По желанию посмотрите пример с синтетическим звуком. Включите камеру, выдайте разрешения и дождитесь подсказки после калибровки.
3. Улыбнитесь и откройте рот без звука. Кот повторит движения, счётчик будет ждать. Протяните «а» с открытым ртом. Когда приложение предложит проверку, присутствующий врач вводит код и подтверждает, что лично услышал нужный звук.
4. Ребёнок увидит награду и сможет надеть звёздочку. В истории появится запись о движении и подтверждении врача. После перезапуска баланс и история сохранятся.

Встроенная модель MediaPipe обрабатывает кадры на устройстве. Микрофон определяет наличие голосового сигнала в окне движения. Для детского режима произношение оценивает присутствующий врач. Задания, история и настройки хранятся локально. [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)
